# Graphical Blackjack Game

A graphical Blackjack game developed in C with an interactive GUI. The game includes deck management, card shuffling and dealing, Blackjack logic, hit/stand gameplay, and win/loss detection.

## Features

- Graphical user interface
- Standard 52-card deck
- Card shuffling and dealing
- Player and dealer hands
- Hit and Stand gameplay
- Blackjack detection
- Automatic hand total calculation
- Dealer logic
- Win, lose, and tie detection
- Remaining card counter
- New Game, Help, and Exit options
- Mouse-based GUI interaction

## Blackjack Rules

The game follows standard Blackjack rules:

- Number cards (2–10) are worth their face value.
- Jack, Queen, and King are worth 10 points.
- Aces can be worth 1 or 11 points depending on the hand.
- The player and dealer are initially dealt two cards.
- The player can choose to **Hit** or **Stand**.
- The dealer continues drawing cards until reaching at least 17.
- The hand closest to 21 wins.
- A hand exceeding 21 is a bust.
- A Blackjack is detected automatically.

## Technologies

- **C**
- **X11 Graphics Library**
- **GCC**
- **Linux**

## Gameplay

1. Start a new game.
2. The player and dealer are dealt two cards.
3. Choose **Hit** to draw another card or **Stand** to end the player's turn.
4. The dealer plays according to the game rules.
5. The final hands are compared.
6. The game displays whether the player won, lost, or tied.
